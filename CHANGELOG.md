## 0.1.0 — 2026-10-17

- A domain-neutral, explicitly invoked workflow Skill for Codex and OpenCode.
- A relay-only controller, one planner, one implementer per task, and one integrated tester.
- Per-run task adaptation with bounded scope, execution, retries and repair rounds.
- Candidate freezing, evidence binding and file-based recovery across clients.
- A Python installer that preflights every file and preserves existing differences.
- English and Chinese documentation, practical examples and offline CI checks.

The initial release does not claim exhaustive live runtime coverage or measured token savings.
